# TV Library Maintenance

A Windows setup wizard and read-only Analyze tool for TV libraries. Analyze reads the Home locations CSV, downloads folder, configured TV storage folders, and storage capacity. It does not move, rename, delete, or rebalance media files.

## Getting started

Download the `TVLibrarySetup` ZIP from the Releases page and extract it. Run `TVLibrarySetup.exe`, choose the `Home-Server-Tools` folder from the extracted package, select your Home CSV and downloads folder, then add your TV storage folders. Save settings and run Analyze.

The weekly schedule is optional and runs on one selected day and time while you are signed in to Windows. Each user saves their own local settings; the release package contains only example settings.

Analyze supports the existing `TV_Home_Locations.csv` format. See [configuration](TV-Library-Maintenance/Docs/CONFIGURATION.md), [local testing](TV-Library-Maintenance/Docs/TESTING.md), and [tool details](TV-Library-Maintenance/README.md).

This is an early, read-only milestone. Results are observations for review; they are not approved move or rename plans.
